Holdout

An open-source toolchain that makes self-deception structurally impossible in quantitative research — for humans and AI research agents.

让量化研究者与金融 AI 智能体无法自欺：每个结论都必须携带证据、通过门禁、留下防篡改审计痕迹，否则不许发布。MIT 开源，全部可 pip 安装。

One gate chain, seven tools

data → adjust → timing → backtest → falsify → review → publish
  │       │         │         │         │        │
  └───────┴─────────┴─────────┴─────────┴────────┴── AI governance (cross-cutting)

Every artifact — a human conclusion, an AI-generated strategy claim, a piece of public copy — walks the same chain and answers the same question: can this be published, and if not, what is missing? All tools output machine-readable JSON + exit codes, are fail-closed by default, and can be called by agents and CI.

The toolchain

falsification-ledger

fl · pip install falsification-ledger

Hash-chained, append-only pre-registration ledger: write down your claim and the evidence that would kill it before seeing the data, then measure hit rate vs. a random baseline (Wilson 95% CI). Featured in awesome-quant.

GitHubPyPI

ashare-data-immunity

imm · pip install ashare-data-immunity

A-share daily-bar data immunity: cleaning, board-aware price limits (ST date-aware), suspensions, delisting/survivorship audits, SHA-256 snapshots and evidence-tracked repair.

GitHubPyPI

pit-adjuster

padj · pip install pit-adjuster

Point-in-time fixed-basis back-adjustment for A-share prices: corporate-action factor chains, convention-drift detection, snapshot-equivalence gates.

GitHubPyPI

lookahead-free

lf · pip install lookahead-free

Verifiable look-ahead freedom for the value-independent fragment of data pipelines, with a heuristic companion scanner for research code.

GitHubPyPI

factor-qc

qc · pip install factor-qc

Fail-closed quality gate for backtests and factor evidence: DSR / PBO / haircut / MinTRL, plus a probability-calibration companion gate. Refuses to judge without an honest n_trials.

GitHubPyPI

lesson-book

lb · pip install lesson-book

Local-first, deterministic tuition memory for traders: pattern-matched reminders, no LLM, overridable rule tables.

GitHubPyPI

holdout-governance

gov · pip install holdout-governance

Fail-closed governance for AI research artifacts: policy.yml + artifact.json, one check before anything ships. Ships as CLI, reusable GitHub Action, pre-commit hook and MCP server. Glama A-grade.

Philosophy

Feynman's first principle: "You must not fool yourself — and you are the easiest person to fool." The statistics literature (deflated Sharpe, PBO, multiple-testing corrections) attacks the math of self-deception. Holdout attacks the process: pre-registration, fail-closed gates, and tamper-evident audit trails make honesty cheaper than rationalization. Named after the holdout — the data you don't touch until the end, and the juror who won't go along until the evidence is in.
