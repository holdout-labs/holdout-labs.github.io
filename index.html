01 One gate chain, seven tools

data → adjust → timing → backtest → falsify → review → publish
  └────────────── AI governance (cross-cutting) ──────────────┘

Every artifact — a human conclusion, an AI-generated strategy claim, a piece of public copy — walks the same chain and answers the same question: can this be published, and if not, what is missing? All tools output machine-readable JSON + exit codes, are fail-closed by default, and can be called by agents and CI.

03 Try it in 60 seconds

# the whole loop in one command — pre-register, evidence, verdict, hit rate,
# then watch `fl verify` catch a tamper at a specific line number:
pip install falsification-ledger
fl demo

fl demo runs the whole loop on a scratch ledger, then deliberately tampers with one field so you can watch fl verify catch it — about 60 seconds from install to "this is why the hash chain matters".

04 Philosophy

"The first principle is that you must not fool yourself — and you are the easiest person to fool." — Richard Feynman

The statistics literature (deflated Sharpe, PBO, multiple-testing corrections) attacks the math of self-deception. Holdout Labs attacks the process: pre-registration, fail-closed gates, and tamper-evident audit trails make honesty cheaper than rationalization. Named after the holdout — the data you don't touch until the end, and the juror who won't go along until the evidence is in.
